## 📌 Projects

### 🏠 Kohere
**외국인 맞춤형 주거 탐색 플랫폼**

한국에서 집을 구하는 외국인이 조건에 맞는 매물을 찾고, 언어 장벽 없이 실시간으로 소통할 수 있도록 돕는 서비스입니다.

- **실시간 소통** — WebSocket·STOMP 기반 채팅, 다국어 번역 및 FCM 푸시 알림 구현
- **채팅 응답 개선** — 메시지 저장·전송과 번역 처리를 분리하여 번역 지연이 대화를 막지 않도록 개선
- **매물 검색 개선** — MongoDB를 활용해 같은 방이 가격·옵션 조건을 모두 충족하도록 검색하고, 해당 방을 기준으로 가격 표시 및 정렬

[GitHub Repository →](https://github.com/swyp-app-5th-team1/Kohere-backend)

<br>

### 🧭 MagNavi
**자기장 기반 실내 위치 추정 및 내비게이션**

스마트폰에서 수집한 자기장과 이동 데이터를 활용해, 실내에서도 사용자의 위치를 파악하고 길을 안내하는 서비스입니다.

- **서버 개발** — 센서 데이터를 받아 위치 추정 결과를 반환하는 API 및 데이터베이스 설계
- **위치 추정 개선** — 자기장 보정 알고리즘을 적용해 프로젝트 측정 기준 정확도 72.5% → 97.3% 개선
- **인프라 구축** — AWS EC2·RDS 기반 서버 및 데이터베이스 운영 환경 구축

[GitHub Repository →](https://github.com/ychoik/back_fastapi_my)

<br>

### 📖 Paperdot
**영어 원문과 번역문을 문장별로 연결하는 학습 서비스**

영어 PDF의 원문과 번역문을 문장 단위로 나란히 읽으며, 내용을 이해하고 학습할 수 있도록 돕는 문서 리더 서비스입니다.

- **문서 분석** — PDF에서 텍스트를 추출하고 문장 단위로 분리
- **번역 매칭** — 문장별 번역 결과를 원문과 1:1로 연결하여 저장 및 조회
- **사용자 인증** — OAuth2 로그인 및 JWT 기반 인증 지원

[GitHub Repository →](https://github.com/ychoik/be-paper-reader_myself)
